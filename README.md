# MUD Game - Astro + React

A social simulator built with Astro and React.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack

- Astro - SSR and file-based routing
- React - Interactive UI components
- TailwindCSS - Styling
